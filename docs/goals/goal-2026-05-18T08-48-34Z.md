     - `input_tokens`                                                                                          
     - `cached_input_tokens`                                                                                   
     - `output_tokens`                                                                                         
     - `reasoning_output_tokens`                                                                               
     - `total_tokens`                                                                                          
   - Normalize to:                                                                                             
     - `tokens.input`                                                                                          
     - `tokens.cache_read`                                                                                     
     - `tokens.output`                                                                                         
     - `tokens.reasoning_output`                                                                               
     - `tokens.total`                                                                                          
                                                                                                               
   Implement:                                                                                                  
   1. Create `src/usage-telemetry.ts`.                                                                         
   2. Add focused tests.                                                                                       
                                                                                                               
   Module responsibilities:                                                                                    
   1. `parseCodexTokenUsageFromJsonl(stdout: string)`:                                                         
      - parse newline-delimited JSON,                                                                          
      - ignore invalid/non-usage lines,                                                                        
      - find `type: "token_count"`,                                                                            
      - return the last `payload.info.total_token_usage`,                                                      
      - optionally expose last response usage if useful,                                                       
      - handle empty/missing usage safely.                                                                     
   2. Normalize usage into a stable ClawSweeper token shape:                                                   
      - input                                                                                                  
      - cache_read                                                                                             
      - output                                                                                                 
      - reasoning_output                                                                                       
      - total                                                                                                  
   3. Build sanitized usage event objects with metadata only:                                                  
      - workflow/mode/phase                                                                                    
      - GitHub repo/run id/run attempt/job if env exists                                                       
      - runner name if env exists                                                                              
      - target repo                                                                                            
      - item number / commit sha / job path                                                                    
      - model                                                                                                  
      - reasoning effort                                                                                       
      - service tier                                                                                           
      - sandbox                                                                                                
      - elapsed ms                                                                                             
      - status                                                                                                 
      - tokens                                                                                                 
   4. Add JSONL writer helper for local `usage-events.jsonl`.                                                  
   5. Make future Opik emission pluggable but do not overbuild it yet. A stub/interface is enough if direct    
 Opik upload belongs in Step 4.

   - No raw prompts.                                                                                           
   - No raw model outputs.                                                                                     
   - No raw transcripts in telemetry event payloads.                                                           
   - No secrets, headers, GitHub tokens, API keys, issue bodies, or comment bodies.                            
   - Telemetry parsing/writing must fail soft by default.

 sanitized metadata.

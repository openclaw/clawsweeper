# Head-mismatch dead-letter supersession proof

Production reconcile run `31648987909` at `2026-08-12T22:56:00Z`, the first run with the skip taxonomy from [openclaw/clawsweeper#1147](https://github.com/openclaw/clawsweeper/pull/1147), inspected 125 skipped targets and reported `head_mismatch: 121`, `blocked_alias: 3`, and `active_work: 1`, with zero recoveries. The open DLQ tail held 191 rows: 158 `retry_exhausted`, 31 `tuple_protocol_invalid`, and two `workflow_cancelled`. Samples such as [openclaw/acpx#485](https://github.com/openclaw/acpx/pull/485) and [openclaw/crabpot#245](https://github.com/openclaw/crabpot/pull/245) showed the endgame: immutable publication artifacts for old pull-request heads must never be replayed as current work.

The existing HMAC-authenticated canonical record route is the authority needed to distinguish genuinely superseded work from unexplained drift: `GET /internal/state/records/<repo-slug>/items/<number>`. Its Durable Object envelope contains the canonical content, digest, monotonic revision, and update time. The report content binds `repository`, `number`, `type`, `review_status`, and `pull_head_sha`. A complete same-target report at the live GitHub head proves that a stale dead-letter artifact for another head has been replaced by a durable completed review/publication. No new endpoint is needed.

The authenticated lifecycle audit inventory is useful corroboration—it exposes completed and superseded lanes plus canonical receipt outcomes—but intentionally omits source heads, so it cannot independently prove newer-head supersession. Public queue lane totals are aggregate-only for the same reason.

The bounded stage checks at most ten head-mismatched targets per cycle and resolves at most 20 supported rows per proven target. After reading canonical evidence, it immediately rechecks GitHub and requires the same open node identity and head before mutation. Drift leaves the row open as `head_mismatch_revalidation_changed`. A successful path writes a note with the full newer head and canonical path, sends the Worker a guarded `resolution_outcome: superseded`, and increments publication completed/superseded metrics. Missing, invalid, incomplete, wrong-target, failed, or wrong-head records leave rows open as `head_mismatch_unproven`. `tuple_protocol_invalid` and `workflow_cancelled` rows never enter this resolution path. Dry-run reports the planned counts but performs no mutation.

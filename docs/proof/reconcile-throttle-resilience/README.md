# Reconcile throttle-resilience proof

Production run 31634514031-era evidence showed `inspected_targets=3`, `skipped_targets=125`, and `recovered_targets=0` after one `http_403` plus two attributed `not_inspected_abort` targets. At the same time, the `repository_actions` pool was under sustained pressure (`item_metadata` read throttle first=718, repeat=1197; roughly 6,000 `artifact_download` circuit skips) while the `target_app` pool was nearly idle.

The code investigation found that parked REST checks, standard REST checks, and batched GraphQL canonical discovery all selected `GITHUB_TOKEN`. In the scheduled workflow that variable was `${{ github.token }}`, the same repository Actions credential used by the prior-artifact download and stuck-run Actions API remediation. Round 1 moved those reads to one OpenClaw installation token, which would have failed every target owned outside that installation.

The owner decision preserves cross-owner recovery. The operator now reuses the Worker's canonical GitHub App plumbing—`githubAppCredentials`, `signGithubAppJwt`, `githubAppInstallationId`, and `createGithubAppTokenFor`—to mint a read-only contents/issues/pull-request token for each target owner. Tokens are cached per owner for the cycle, and GraphQL batches are owner-homogeneous. A genuinely missing or revoked installation is a per-target `installation_missing` skip with a bounded sample; it never aborts the cycle. Repository artifact and Actions-run operations remain on `${{ github.token }}`.

The original abort came from https://github.com/openclaw/clawsweeper/pull/973: complete canonical-alias discovery protected active sibling fences and bounded API usage before mutation. https://github.com/openclaw/clawsweeper/pull/1117 added honest per-target diagnostics while deliberately retaining that behavior. The new policy changes only GitHub-confirmed rate-limit or abuse 403s and all 429s: isolated throttles become per-target or per-batch skips, a success resets the counter, and three consecutive throttled calls abort the remaining phase. Authorization and policy 403s, plus every other non-throttle discovery failure, still use the conservative abort path. The existing target, recovery, GraphQL batch, terminal-recheck, and inventory caps remain intact.

The real-behavior contract is in `behavior-contract.md`; the red/green record is in `red-green.md`. The final `run-proof.sh` execution used Docker-backed Crabbox `provider=local-container`, lease `cbx_996ac4ad8ccb` (`brisk-lobster-a96d`), and image `node:24-bookworm`; it passed 14/14 focused scenarios and stopped automatically. `receipt.json` binds the tested head, proof harness, every executable input, and the sanitized transcripts by SHA-256. TruffleHog 3.96.0 found zero verified or unknown secrets.

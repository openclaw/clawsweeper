- Add the write mode of the review record backfill. `backfill-review-records --write [--limit <n>]` adds the `review_record` line (origin `backfill`) to lossless and filled reports only, in batches of 50, skips and counts a report that changed since it was classified, captures each canonical tuple baseline before it writes, and lists the written reports in `changedRecordFiles`. The "Review record backfill" workflow gets a `mode` input (default `dry-run`); `mode: write` runs a separate job that uses setup-state like apply and publishes the written tuples through `publish_reconciled_records` with compare-and-swap on the baseline digest. A written report is typed, so a run that stops part way can run again.

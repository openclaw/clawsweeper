- The agent input scan now accepts submodule pointer changes instead of refusing them as `unsupported_content`. Every PR that bumped a submodule could never be reviewed (for example openclaw/Peekaboo#1185 and #1187, and openclaw/crabpot#886). The pointer's commit ID is still scanned through the raw diff and patch. In a live checkout the submodule path must stay an empty directory, so no submodule content can reach the model unscanned.
